# PDC60 Learning Portfolio

Website version of my PDC60 Conversational AI portfolio. It covers key learnings, activities, old vs new prompts, and reflections for Modules 1 to 6, Agentic AI, and the Final Project.

**Igor P. Toledano** · BSIT 4A · Prof. Adriane Brent Castro

## View it

Hosted with GitHub Pages: open the repository's **Settings → Pages** to see the live URL.

## Files

- `index.html`: the whole portfolio, one page
- `style.css`: styles
- `script.js`: scroll animations and active nav highlighting
- `assets/`: screenshots of the Athena AI final project

No build step is needed. Open `index.html` in a browser to view it locally.
